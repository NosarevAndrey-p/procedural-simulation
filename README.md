### Web flocking animation with procedurally generated animals using PIXI js library to display grafics.

## View Live Demo

You can view the interactive simulation here: **[Procedural Animation Simulation](https://nosarevandrey-p.github.io/procedural-simulation/)**

## Features

- **Procedurally Generated Animals**: Fish, Lizards, and more with realistic body mechanics
- **Flocking Behavior**: Boids simulation with alignment, cohesion, and separation behaviors
- **Interactive Controls**: 
  - Change animal types (Fish, Lizard)
  - Customize animal colors (body, fins, eyes, outline)
  - Adjust the number of animals
  - Toggle between low and high resolution for performance optimization
  - Control simulation parameters
- **Multiple Rendering Options**: PIXI.js (WebGL) for optimal performance
- **Ripple Effects**: Interactive ripple animation on mouse clicks

## Getting Started

1. Clone the repository
2. Open `index.html` in a modern web browser
3. Use the Settings panel to customize the simulation

## Technologies

- **JavaScript (ES6+)**
- **PIXI.js** - 2D rendering library
- **HTML5 Canvas**
- **CSS3**
